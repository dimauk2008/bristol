# Avito Tracker

Отслеживание товаров на Avito с уведомлениями в веб-интерфейсе и хранением данных в SQLite.

## Возможности

- Несколько независимых списков-источников (своя ссылка на поиск, свой город), переключаются чипами сверху
- Сортировка выдачи по дате (`s=104`) — первая страница Avito всегда отдаёт самые свежие объявления, отключается чекбоксом в настройках списка
- Фильтр «Период» (24 часа / 3 дня / 7 дней / всё время) — по дате публикации с Avito, а если её нет, то по моменту обнаружения; по умолчанию показываются только объявления за 24 часа
- Городовой фильтр: объявления других городов из выдачи отсекаются
- Три вида отображения: таблица / карточки / компактный список, поиск по названию, сортировка (сначала новые, по дате публикации, по цене, по названию)
- Уведомления о новых объявлениях и об изменении цены — в интерфейсе, через WebSocket и системные уведомления браузера
- Смена цены, отметка «NEW», отметка «пропало» (объявление исчезло из выдачи двух раз подряд)
- Автоопрос раз в 15 минут (настраивается), ручной запуск в один клик, журнал сканов
- Фото, цены, локация и относительная дата публикации с Avito

## Запуск

```powershell
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000

Или просто `start.bat`.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET/POST | `/api/sources` | Списки-источники: получить / добавить |
| PUT/DELETE | `/api/sources/{id}` | Изменить / удалить список |
| GET | `/api/listings?source_id=&q=&active=&fresh=&sort=&limit=&offset=` | Объявления, `fresh` = `24h\|3d\|7d\|all`, `sort` = `recent\|published\|price_asc\|price_desc\|title` |
| GET | `/api/notifications?source_id=&unread=&limit=&offset=` | Уведомления |
| POST | `/api/notifications/read` | Отметить прочитанными (`{"ids":[...],"source_id":1}`, `ids:null` — все) |
| GET | `/api/stats?source_id=` | Счётчики и статус сканера |
| GET/PUT | `/api/settings` | Интервал опроса (секунды) |
| POST | `/api/scan` | Запустить скан вручную, `{"source_id":1}` или `{}` — все активные |
| GET | `/api/scans?source_id=` | Журнал сканов |
| WS | `/ws` | realtime-события (`hello`, `scan_status`, `scan_finished`, `notification`, `stats`) |

## Важно про Avito

Avito защищается от частых запросов: при слишком частом опросе IP может уйти за капчу (HTTP 429 «Доступ ограничен: проблема с IP»). Трекер в этом случае не долбит ретраями — записывает ошибку в журнал и ждёт следующего цикла. Если интервал поставить меньше 5 минут, риск блокировки растёт.

Для устойчивой работы нужны куки браузера: положите `cookies.json` рядом с проектом (куки перечитываются перед каждым сканом). Файл содержит секреты и не должен попадать в репозиторий — он в `.gitignore`.

Сортировка по дате реализована параметром `?s=104` в ссылке источника; он добавляется автоматически при сохранении списка.

## Структура

```
app/
  main.py       FastAPI: REST, WebSocket, статика
  tracker.py    цикл опроса, сравнение с БД, генерация уведомлений
  scraper.py    HTTP-запрос к Avito и разбор HTML
  urls.py       работа с параметрами ссылки источника (s=104)
  models.py     SQLAlchemy-модели (sources, listings, notifications, scans, settings)
  schemas.py    Pydantic-модели
  database.py   подключение SQLite + миграции
  events.py     менеджер WebSocket-подключений
  config.py     настройки (города, интервалы, пути)
  static/       веб-интерфейс (HTML/CSS/JS)
```
