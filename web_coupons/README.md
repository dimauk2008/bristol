# Bristol Coupons & Card — веб-панель

Панель для аккаунта «Бристоль»: **выдача купонов по ссылке на время** и **показ личной карты** (Data Matrix).

Всё работает **без ADB и эмулятора** — только через API Бристоля (`api.mobile.bristol.ru`).

## Возможности

- **Сессии на время** — выдать доступ к карте/купонам на 15 мин … 30 дней или бессрочно.
- **Купоны** — выдача купона **один раз** по ссылке `/g/{token}`, со сроком действия. Data Matrix (ISO/IEC 16022) кодирует номер купона — как в приложении.
- **Карта «Мир скидок»** — страница `/s/{sid}/card` показывает **Data Matrix** с обёрткой `[B+]` + base64 (структура кода приложения: card_id, ts, device, external_id, подписанный сервером). Код меняется каждый час, страница обновляется сама и по кнопке.
- **Названия и скидки купонов** — извлекаются OCR (Tesseract) при локальной синхронизации; в проде приходят из `seed_coupons.json`.
- **Автообновление** — админка опрашивает `/api/admin/data`, страницы купонов/карты обновляются сами.
- **Админка** — вход по паролю (`ADMIN_PASSWORD`), PBKDF2 + кука на HMAC.

## Быстрый запуск (локально)

```powershell
pip install -r web_coupons\requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8001 --app-dir web_coupons
```

Открыть http://127.0.0.1:8001 → логин `bristol` (если `ADMIN_PASSWORD` не задан).

## Переменные окружения

См. `.env.example` в корне репозитория.

| Переменная | Зачем |
|---|---|
| `BRISTOL_REFRESH_TOKEN` | **Главное для прода.** Refresh-токен приложения — по нему всё работает без ADB. |
| `BRISTOL_TOKEN` | Текущий access-токен (опционально). |
| `BRISTOL_EXTERNAL_ID` | Guid пользователя (обычно берётся из JWT). |
| `BRISTOL_CARD_DEVICE_ID` | Девайс в кодах карты. Дефолт `SP1A.210812.016` (реальный телефон). |
| `BRISTOL_X_API_KEY` | API-ключ приложения (есть в APK). |
| `ADMIN_PASSWORD` | Пароль входа в админку. |
| `DB_PATH` | Путь к SQLite. Пусто — `web_coupons/coupons.db`. |

## Деплой на Railway

Репозиторий уже готов: `Procfile`, `runtime.txt`, `requirements.txt`.

1. Залейте репозиторий на GitHub.
2. В Railway: **New Project → Deploy from GitHub**, выберите репозиторий.
3. Railway сам подхватит Python (`runtime.txt`) и запустит `uvicorn ... --app-dir web_coupons` (`Procfile`).
4. В **Variables** задайте `BRISTOL_REFRESH_TOKEN` (обязательно) и `ADMIN_PASSWORD`.
5. Откройте выданный URL → `/login` → админка.

### Важные нюансы прода

- **OCR названий/скидок в проде не работает** — на Railway нет Tesseract. Купоны подтягиваются из `web_coupons/seed_coupons.json` (261 купон, 261 название, 253 скидки). Data Matrix купонов считается из номера — работает всегда.
- **Картинки купонов** лежат в `web_coupons/static/img` (в репозитории; git хранит дубликаты один раз, итог ~22 МБ).
- **SQLite эфемерен** на Railway: файл слетает при редеплое. Купоны восстановятся из seed, но **выданные ссылки (`/g/{token}`) и сессии пропадут**. Чтобы сохранять их — подключите **Volume** и задайте `DB_PATH` на него.
- **Токен** с течением времени обновляется сам (`refresh`), так что после первоначальной настройки вмешательство не требуется. Если сессия истечёт — обновите `BRISTOL_REFRESH_TOKEN`.

## Что где

```
web_coupons/
  main.py          FastAPI: админка, публичные страницы, выдача купонов, карта
  bristol.py       API Бристоля + OCR + генерация кодов карты/купонов
  db.py            SQLite (sessions, coupons, bristol_*, settings, coupon_grants)
  qr.py            генерация QR (ISO/IEC 18004)
  datamatrix.py    генерация Data Matrix (ISO/IEC 16022) — коды купонов и карты
  seed_coupons.json  сид купонов для чистой БД (номер, название, скидка, сроки)
  templates/       index, card-ses, bristol_coupon, coupon_grant и др.
  static/img/      картинки купонов
```

## Ограничения / безопасность

- Проект — личный инструмент. **Не публикуйте репозиторий публично**, если в БД есть ваши токены/телефон — файлы `coupons.db` и `bristol_prefs.xml` исключены из git, но проверьте, что в остальном нет секретов.
- Купон/карта — коды вашего собственного аккаунта. Отдавать их кому-то — значит делиться своей картой.
